## Deviations

- **TypeScript placement.** The design put `families.ts`, `domains.ts`,
  the maxima and `issuePath` in the binding; CLAUDE.md's placement rule puts
  host-neutral modules in `packages/acs-core/src/`, so they are there
  (`agents.ts`, `families.ts`, `domains.ts`, `issues.ts`) and the binding
  keeps what reads Standard Agents state (`deriveAgentManifest`,
  `taskRefusal`, `declaredAgents`, `lintDelegationTargets`). `toIssue` was
  not added: `issuePath` is the §9.8 projection a host needs.
- **No model names.** The design's model-family examples, vectors and guide
  table name real model lines; by the maintainer's rule every example and
  vector uses fictional identifiers (`acme-large-2`, `us.acme...`,
  `Zephyr/...`, `z3-mini`). The rule is unchanged.
- **Namespace keys in diagnostics.** A finding in another catalog of a set
  is reported with that catalog's `catalog` id and the workflow's own name;
  its `path` points into that catalog's document, as §9.8 says.
- **Exact `path` for nested binding keys.** Besides the design's user-key
  sites, the bindings checker's nested literal keys (a `task` mapping's
  keys, `wait.correlate` keys) carry pointer tokens (`Report::stamp_since`),
  so `path` is exact there too.
- **W616 for 1.2 features (S6's list).** `continues` is a `FEATURES` entry;
  the catalog manifest's W616 is reported by `catalog::check_manifest` (it
  needs the file header), and a qualified `invoke` target's by
  `invoke::check` (it needs the catalog set: `Resolver::resolves_qualified`),
  once per workflow at its first such step, as `FEATURES` rows are reported.
- **§10.2 L4 bullet.** L4 is "Patches" in this Standard; the execution
  bullet went to §10.5 (class EX), where executor requirements are.
- **Python `effective_flags`.** Raises `UnboundedDelegation` only when the
  caller passes the workflow (`ensure_checkpoint_before_step` and the tracer
  do); without it, it gives the 1.1 view, so existing callers are unchanged.
- **Runtime fixtures.** `invoke_bare_name_in_library` is folded into
  `invoke_qualified_library` (the primary catalog has an `inner` of another
  capability, and the run reaches the library's); fifteen fixtures, not
  sixteen, before the S6 merge; seventeen after it (the two profile
  integration runs), eighteen after review round 1
  (`delegate_continues_v11_unchecked`).
