# Contact

The Agent Capability Standard is developed in public on GitHub, and that is
the one place to reach the people who maintain it. There is no email address,
phone number or contact form for the site.

## Questions, mistakes and proposals

- **Report a problem or ask a question:** open an issue in the
  [repository's issue tracker](https://github.com/synaptiai/agent-capability-standard/issues).
  Say which page you were reading (its URL) and what you expected to find.
  Issues are public, so do not include personal or confidential information.
- **Propose a change to the standard:** larger changes go through the RFC
  process that [governance](../../spec/GOVERNANCE.md) describes; the
  [contributing guide](../../CONTRIBUTING.md) explains how to open a pull
  request.
- **Fix a page:** every page is built from a file in the repository, and the
  page footer links it. A pull request that changes that file changes the
  page.

## Security issues

Do not report a security vulnerability in a public issue. Follow the
responsible disclosure process in the [security model](../../spec/SECURITY.md#7-responsible-disclosure).

## Conduct

Everyone who takes part in the project's issues and pull requests is asked to
follow the [code of conduct](../../CODE_OF_CONDUCT.md).
